# Developer Code of Conduct: Security & Privacy

## 1. Core Commitment

As a developer at our company, you are a guardian of our users' data. You are expected to prioritize security and privacy in all aspects of your work.

## 2. Your Responsibilities

-   **Handle Data with Care:** Treat all user data as confidential. Never access, copy, or share user data outside of what is strictly required to perform your job. Never use real customer data in non-production environments (development, staging).
-   **Write Secure Code:** You are responsible for following the `Secure Coding Guidelines`. Proactively identify and fix security vulnerabilities in your code and in code you review.
-   **Report Vulnerabilities:** If you discover a security flaw or a potential data breach, report it immediately to the security team via the established internal process. Do not attempt to hide it or ignore it.
-   **Respect Privacy:** Implement features in a way that respects user privacy choices. Do not build workarounds to bypass privacy controls.
-   **Continuous Learning:** Stay informed about emerging threats and modern security best practices.

## 3. Consequences of Non-Compliance

Violations of this Code of Conduct or other security policies can have severe consequences, including disciplinary action up to and including termination of employment. Unlawful actions may also lead to legal prosecution.
